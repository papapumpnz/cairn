# WP01 — Canonical serialization, content-addressed storage, and artifact envelopes

## Objective

Provide immutable, replayable, cross-process artifacts with stable semantic identity.

## Dependencies

WP00

## Owned scope

`cairn-core`, `cairn-cas`, shared hash and artifact schemas

## Inputs

Artifact contracts in `03_CAIRN_INTERFACES.md`.

## Deliverables

Canonical CBOR encoder/decoder, BLAKE3 IDs, append-only CAS, artifact validation, schema/version negotiation, and crash-safe local storage.

## Required design

Define canonical ordering for maps, sets, enums, floats, parent hashes, and optional fields. Separate semantic payload hashes from producer metadata where required. Store blobs by hash in a fanout directory or packfile index; write through temporary files, fsync, then atomic rename. Maintain an append-only journal for artifact registration. Validate payload length, hash, schema, parent existence policy, derivation acyclicity where applicable, and maximum decode depth. Support memory-mapped reads and zero-copy slices for large packed values.

## Public API obligations

`CanonicalEncode`, `CanonicalDecode`, `Cas::put`, `Cas::get`, `Cas::verify`, `ArtifactEnvelope<T>`, schema registry, and migration reader for additive compatible fields.

## Test plan

Golden byte fixtures across architectures; randomized round trips; map insertion-order invariance; hash collision simulation through injected fake hasher; torn-write recovery; concurrent put of same blob; malicious oversized length; deep nesting; unknown schema; parent cycle fixture.

## Acceptance criteria

Identical semantic values produce identical bytes and IDs across repeat runs; 10 million small artifact round trips without mismatch; concurrent idempotent writes; recovery after forced process termination; cached 1 MB blob read throughput above 1 GB/s on baseline storage or documented machine-normalized equivalent.

## Forbidden shortcuts

Do not use JSON as canonical storage. Do not include wall-clock timestamps in semantic hashes. Do not silently migrate incompatible schemas.

## Mandatory operating constraints

- CPU-only and transformer-free. Run `cairn-check` before handoff.
- No ARC task IDs, full-grid hashes, memorized outputs, or task-family branches in production code.
- Deterministic semantic output for fixed input, semantics version, seed, and work budget.
- Canonical serialization for every persistent public type.
- Exact errors: distinguish invalid input, unsupported semantics, capacity cap, timeout, and internal defect.
- Add metrics before optimizing. A speed claim requires the naive or previous baseline on the same machine.
- No evaluation split access.

## Required handoff

Return a committed implementation, public API documentation, test commands, benchmark commands, evidence artifacts, acceptance-criterion table, known limitations, and the exact downstream interface tag.
