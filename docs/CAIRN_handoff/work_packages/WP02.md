# WP02 — Packed finite spatial fields and CPU geometry kernels

## Objective

Deliver an exact high-throughput finite spatial-field service for raster-like frontends without making cognition depend on grids or categorical meanings.

## Dependencies

WP00

## Owned scope

`cairn-spatial`, adapter-side spatial support

## Inputs

Generic finite-field bounds and exact spatial reference semantics from the master design.

## Deliverables

Generic `FiniteField<T>`, packed masks, index sets, transforms, connected components under supplied adjacency, geometry, rasterization, overlay, and naive references.

## Required design

Use specialized fixed masks for up to 32 by 32 and 64 by 64, with dynamic tiled storage beyond. Cache equality masks for arbitrary exact element values without assigning meaning. Implement D4 transforms, translation, crop, pad, integer scale, component labeling under supplied 4/8 or explicit adjacency, contours, holes, bounding boxes, line/ray/rectangle rasterization, set morphology, distance transforms, shape signatures, and conflict-aware overlay. SIMD is optional behind audited feature detection; scalar semantics are authoritative. This crate is a frontend service and cannot appear in generic REG, RKL, entity, event, or verifier public types.

## Public API obligations

`FiniteField<T>`, `IndexSet`, `PackedMask`, `Transform2`, `ComponentIndex`, `SpatialOverlay`, exact coordinate conversions, and iterator-free bulk operations where possible.

## Test plan

Exhaustive binary fields through 4 by 4 for topology operations; transform group laws; randomized comparison to a nested-vector reference for 100,000 fields spanning Boolean, integer, and categorical element types; overlay conflicts; zero/one-element dimensions; 32, 64, and dynamic boundaries; endian round trips; malformed packed data.

## Acceptance criteria

All generic reference comparisons pass; component labeling median is below 3 microseconds on representative 30 by 30 fields; common mask operations exceed 20 million operations per core per second; no ARC vocabulary or semantic categorical role enters the API; no unsafe exists outside audited SIMD and packed-copy modules.

## Forbidden shortcuts

Do not assign semantic meaning to field values. Do not expose `Grid`, ARC color, task, pair, or operation types. Do not make cognition crates depend on this frontend service. Do not optimize before reference tests exist.

## Mandatory operating constraints

- CPU-only and transformer-free. Run `cairn-check` before handoff.
- No ARC task IDs, full-grid hashes, memorized outputs, or task-family branches in production code.
- Deterministic semantic output for fixed input, semantics version, seed, and work budget.
- Canonical serialization for every persistent public type.
- Exact errors: distinguish invalid input, unsupported semantics, capacity cap, timeout, and internal defect.
- Add metrics before optimizing. A speed claim requires the naive or previous baseline on the same machine.
- No evaluation split access.

## Required handoff

Return a committed implementation, public API documentation, test commands, benchmark commands, evidence artifacts, acceptance-criterion table, known limitations, and the exact downstream interface tag.
