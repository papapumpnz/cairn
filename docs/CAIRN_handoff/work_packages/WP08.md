# WP08 — Structure evidence detectors

## Objective

Supply cheap, task-independent evidence for panels, separators, repetition, symmetry, topology, and candidate symbols.

## Dependencies

WP02, WP03, WP07

## Owned scope

detector modules in `cairn-entity` and `cairn-reg`

## Inputs

Grid and entity catalogs.

## Deliverables

Evidence facts with confidence, derivations, detector benchmarks, and manual-audit fixtures.

## Required design

Detect separator rows/columns and panel frames, periodic translations, D4 symmetry support, repeated motifs under color normalization, grid and checker structure, contours and holes, lines and rectangles, palette roles by frequency and spatial distribution, small isolated token candidates, and local coordinate frames. Detectors emit evidence, not final semantics. Competing hypotheses coexist.

## Public API obligations

`Detector` trait, `EvidenceBatch`, detector registry, feature flags, and per-detector metrics.

## Test plan

Positive and adversarial negative synthetic suites; noisy near-symmetry; accidental separator colors; nested panels; repeated but semantically unrelated motifs; calibration of exact versus heuristic evidence.

## Acceptance criteria

Zero false exact facts on the committed exact-detector suite; heuristic detector precision and recall reported separately; total detector median below 30 ms per ARC task; each result has a reproducible derivation and supporting cell set.

## Forbidden shortcuts

Do not promote a detector output directly to a control role. Do not use full task outputs in input-only detection except explicitly pair-relative difference detectors.

## Mandatory operating constraints

- CPU-only and transformer-free. Run `cairn-check` before handoff.
- No ARC task IDs, full-grid hashes, memorized outputs, or task-family branches in production code.
- Deterministic semantic output for fixed input, semantics version, seed, and work budget.
- Canonical serialization for every persistent public type.
- Exact errors: distinguish invalid input, unsupported semantics, capacity cap, timeout, and internal defect.
- Add metrics before optimizing. A speed claim requires the naive or previous baseline on the same machine.
- No evaluation split access.

## Required handoff

Return a committed implementation, public API documentation, test commands, benchmark commands, evidence artifacts, acceptance-criterion table, known limitations, and the exact downstream interface tag.
