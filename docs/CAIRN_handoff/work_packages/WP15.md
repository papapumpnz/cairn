# WP15 — Constructor and coordinate-expression synthesis

## Objective

Synthesize exact variable-arity outcome structures, placement, shape, categorical values, and observation-relative geometry where present from provenance evidence.

## Dependencies

WP09, WP12, WP13

## Owned scope

`cairn-construct`

## Inputs

Target entities and unmatched regions, candidate sources, role mappings, e-graph, finite-domain solver.

## Deliverables

Constructor expressions, relation anchors, optional coordinate formulas, categorical-value functions, group mappings, and construction proofs.

## Required design

Work backward from target cells and entities. Enumerate source candidates by normalized shape and topology, anchor candidates from extrema/intersections/references/panels, then solve low-cost formulas using bounded arithmetic and relation-derived vectors. Support copy/transform, line/rectangle spans, set comprehensions, repetition-until predicates, scale, merge, split, and composition from multiple sources. Batch-evaluate expressions and canonicalize. Variable-arity constructors bind entity sets and emit one or more targets per binding.

## Public API obligations

`ConstructorProblem`, `ConstructorSynthesizer`, `ConstructorExpr`, `AnchorExpr`, `ColorExpr`, `ConstructionCertificate`, and missing-constructor core helpers.

## Test plan

Count extrapolation; positions beyond training range; multicolor shapes; nonuniform scale negatives; source-relative and reference-relative anchors; panel-local coordinates; merge/split; overlap conflicts; brute-force small formula comparison.

## Acceptance criteria

At least 95% held-out exact output on T1 variable-arity suite; at least 85% on multicolor construction suite; every emitted cell has source or bounded constructor provenance; p95 below 5 s for invention-tier cases and below 500 ms for base-tier cases.

## Forbidden shortcuts

Do not encode fixed output slots for variable-count tasks. Do not use expected test dimensions or output cells.

## Mandatory operating constraints

- CPU-only and transformer-free. Run `cairn-check` before handoff.
- No ARC task IDs, full-grid hashes, memorized outputs, or task-family branches in production code.
- Deterministic semantic output for fixed input, semantics version, seed, and work budget.
- Canonical serialization for every persistent public type.
- Exact errors: distinguish invalid input, unsupported semantics, capacity cap, timeout, and internal defect.
- Add metrics before optimizing. A speed claim requires the naive or previous baseline on the same machine.
- No evaluation split access.

## Required handoff

Return a committed implementation, public API documentation, test commands, benchmark commands, evidence artifacts, acceptance-criterion table, known limitations, and the exact downstream interface tag.
