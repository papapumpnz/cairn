# WP22 — Quarantined ARC-AGI-1/2 adapter and task runner

## Objective

Losslessly translate official ARC records into generic learning problems without introducing ARC semantics into cognition crates.

## Dependencies

ADR-0007 adds WP34 as a developmental dependency. Existing adapter regression
work may continue, but no ARC failure may introduce a named core mechanism.

WP02, WP06, WP29

## Owned scope

`adapters/arc12`, `cairn-arc12`

## Inputs

Dataset roots supplied at runtime, generic frontend and cognition traits, verifier.

## Deliverables

Strict JSON parser, adapter lowering and round-trip proofs, training/public-eval capability separation, answer writer, suite runner, and task visualization for development only.

## Required design

Validate dimensions, categorical cell values, train/test structure, and attempts. Hash canonical task bytes, then lower them into `LearningProblem`, `Observation`, `Demonstration`, and `PredictionRequest`. Keep `ArcTask`, `ArcGrid`, color naming, split naming, and answer encoding inside the adapter. Expose only normalized evidence to cognition, never path-derived semantics. Use capability tokens for training versus evaluation roots. Evaluation runner seals per-task diagnostics until completion. Support deterministic task ordering, journal resume, and no partial overwrite.

## Public API obligations

`ArcTaskLoader`, `ArcAdapter`, `DatasetCapability`, generic learner integration, `SuiteRunner`, answer serialization, and development visualization command.

## Test plan

Malformed JSON, uneven rows, invalid colors, missing train/test, path traversal, evaluation capability misuse, deterministic ordering, interrupted-run resume, answer formatting against fixtures.

## Acceptance criteria

All official public files parse; malformed fixtures are rejected precisely; adapter lowering and supported-output round-trip are exact; cognition crates remain ARC-vocabulary-free; ordinary development binaries cannot enumerate evaluation roots; runner overhead is below 5 ms per task excluding solve.

## Forbidden shortcuts

Do not expose task filenames to cognition. Do not import evaluation data in unit tests. Do not move ARC types or operations into a general crate.

## Mandatory operating constraints

- CPU-only and transformer-free. Run `cairn-check` before handoff.
- No ARC task IDs, full-grid hashes, memorized outputs, or task-family branches in production code.
- Deterministic semantic output for fixed input, semantics version, seed, and work budget.
- Canonical serialization for every persistent public type.
- Exact errors: distinguish invalid input, unsupported semantics, capacity cap, timeout, and internal defect.
- Add metrics before optimizing. A speed claim requires the naive or previous baseline on the same machine.
- No evaluation split access.

## Required handoff

Return a committed implementation, public API documentation, test commands, benchmark commands, evidence artifacts, acceptance-criterion table, known limitations, and the exact downstream interface tag.
