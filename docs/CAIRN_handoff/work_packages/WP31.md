# WP31 — CPU audio and video frontend spikes

## Objective

Test temporal modality normalization into entities, events, tracks, and relations.

## Dependencies

WP26, WP29

## Owned scope

`frontends/audio`, `frontends/video`

## Inputs

Pre-registered synthetic and small real audio/video suites.

## Deliverables

Audio event graph, video tracking adapter, temporal uncertainty, and measured limits.

## Required design

Audio: waveform windows, FFT or filter-bank features, onset/offset, pitch/rhythm candidates, repetition and source hypotheses. Video: frame adapter, flow or keypoint motion, object tracks, camera motion, event segmentation, and links to temporal REG. Use bounded streaming buffers and CAS-backed raw media.

## Public API obligations

Frontend implementations and streaming observation API.

## Test plan

Tempo/pitch changes, noise, overlapping events, camera motion, occlusion, variable frame rate, long stream memory, malformed media.

## Acceptance criteria

Meet separately pre-registered event and tracking metrics; no unbounded active history; CPU-only attestation; one end-to-end transformation or planning demo per modality with replayable evidence.

## Forbidden shortcuts

Do not merge audio and video claims into one metric. Do not let media decoding threads escape resource accounting.

## Mandatory operating constraints

- CPU-only and transformer-free. Run `cairn-check` before handoff.
- No ARC task IDs, full-grid hashes, memorized outputs, or task-family branches in production code.
- Deterministic semantic output for fixed input, semantics version, seed, and work budget.
- Canonical serialization for every persistent public type.
- Exact errors: distinguish invalid input, unsupported semantics, capacity cap, timeout, and internal defect.
- Add metrics before optimizing. A speed claim requires the naive or previous baseline on the same machine.
- No evaluation split access.

## Required handoff

Return a committed implementation, public API documentation, test commands, benchmark commands, evidence artifacts, acceptance-criterion table, known limitations, and the exact downstream interface tag.
