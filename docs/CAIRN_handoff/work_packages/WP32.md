# WP32 — Proof-backed knowledge subsystem and transformer-free text frontend

Implementation checkpoint (2026-07-11): the source-bound relational knowledge
store, temporal/confidence model, contradiction retention, retrieval index,
reversible merge proposals, and executable mechanism references are complete
for structured evidence. Deterministic text parsing, grammar induction, and
coreference remain open.

## Objective

Acquire typed, temporal, contradictory, source-linked declarative knowledge and executable schemas, with constrained text as one frontend.

## Dependencies

WP03, WP04, WP06, WP23, WP29

## Owned scope

`cairn-knowledge`, `frontends/text`

## Inputs

Pre-registered controlled-language, technical-document, and knowledge-retrieval suites.

## Deliverables

Claim store, temporal validity, provenance, entity-resolution proposals, contradiction artifacts, causal and taxonomic indexes, executable schema promotion, tokenizer/morphology, chart parser, semantic frames, and source citations.

## Required design

Store knowledge as relational assertions and executable schemas, never embedded-vector truth. Claims retain source observations, confidence, and temporal validity. Entity resolution produces reversible merge proposals. Contradictions coexist as first-class artifacts. Start the text adapter with deterministic lexing, finite-state morphology, weighted context-free or combinatory parsing, typed semantic templates, coreference constraints, and source-aware insertion. Grammar induction may propose rules. A small CPU recurrent, reservoir, or state-space model may rank alternatives but cannot fabricate facts or bypass source links.

## Public API obligations

`KnowledgeStore`, `KnowledgeClaim`, `KnowledgeConflict`, `EntityResolution`, `ProcedureSchema`, `KnowledgeQuery`, text frontend, `SourceSpan`, and parse-forest artifact.

## Test plan

Ambiguous parses, negation, quantifiers, coreference, tables, conflicting sources, unknown terms, source-span replay, long-document streaming.

## Acceptance criteria

Every claim has replayable sources and temporal scope; contradictions coexist; entity merges are reversible proposals; executable schemas pass verifier and promotion gates; meet a pre-registered controlled-language semantic parse bar or publish an honest negative result; no transformer dependency; unsupported language scope is explicit.

## Forbidden shortcuts

Do not advertise unrestricted language understanding. Do not convert retrieval confidence into truth.

## Mandatory operating constraints

- CPU-only and transformer-free. Run `cairn-check` before handoff.
- No ARC task IDs, full-grid hashes, memorized outputs, or task-family branches in production code.
- Deterministic semantic output for fixed input, semantics version, seed, and work budget.
- Canonical serialization for every persistent public type.
- Exact errors: distinguish invalid input, unsupported semantics, capacity cap, timeout, and internal defect.
- Add metrics before optimizing. A speed claim requires the naive or previous baseline on the same machine.
- No evaluation split access.

## Required handoff

Return a committed implementation, public API documentation, test commands, benchmark commands, evidence artifacts, acceptance-criterion table, known limitations, and the exact downstream interface tag.
