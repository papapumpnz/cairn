## Objective

Integrate one cognition runtime around universal Mechanism IR with separate
online, consolidation, verification, and curriculum authority. Demonstrate it
unchanged across three non-ARC domains before ARC integration is a dependency.

Integrate one cognition runtime across task learning, continual learning, interactive causal learning, knowledge use, and three adapters.

## Dependencies

WP18, WP19, WP20, WP21, WP22, WP23, WP24, WP28, WP29, WP32, WP33

## Owned scope

top-level `cairn` binary, integration configuration, release profiles

## Inputs

All cognition crates, memory, planning, knowledge, local swarm, generic benchmark harness, and grid-transformation, gridworld, and vector-graphics adapters.

## Deliverables

Single-node and swarm runtimes, staged budgets, checkpoint/resume, three-loop metrics, failure taxonomy, profiling reports, three-domain evidence packs, and optional ARC adapter reports.

## Required design

Implement the common cognition runtime once and inject adapters through generic observation, transition, goal, and verification contracts. Run task-local induction, memory proposal/promotion, and interactive world learning as visible stages. Maintain problem frontiers, belief modes, stop criteria, intervention budgets, and attempt budgets. Profile perception, theory search, memory, planning, knowledge, execution, invention, and verification. Optimize only measured bottlenecks while preserving reference semantics.

## Public API obligations

`cairn learn`, `cairn interact`, `cairn solve`, `cairn suite`, configuration schema, stage checkpoints, and top-level `CognitionRuntime` implementation.

## Test plan

End-to-end omitted-concept suites, frozen continual curriculum, unknown-world episodes, three-domain conformance, ARC quarantine lint, timeout at every stage, resume, memory cap, swarm determinism, memory-off, invention-off, and verifier failure injection.

## Acceptance criteria

GLL-1 through GLL-6 pass or an honest narrowed-scope report is published; one core revision runs all three required domains; median and p95 resources are reported; no failure is unclassified; all predictions and plans are independently verified; release binary passes attestation.

## Forbidden shortcuts

Do not patch individual diagnostic tasks. Do not hide missing learning loops behind ARC scores or legacy solver fallback. Do not fork cognition by adapter.

## Mandatory operating constraints

- CPU-only and transformer-free. Run `cairn-check` before handoff.
- No ARC task IDs, full-grid hashes, memorized outputs, or task-family branches in production code.
- Deterministic semantic output for fixed input, semantics version, seed, and work budget.
- Canonical serialization for every persistent public type.
- Exact errors: distinguish invalid input, unsupported semantics, capacity cap, timeout, and internal defect.
- Add metrics before optimizing. A speed claim requires the naive or previous baseline on the same machine.
- No evaluation split access.

## Required handoff

Return a committed implementation, public API documentation, test commands, benchmark commands, evidence artifacts, acceptance-criterion table, known limitations, and the exact downstream interface tag.

## Relational-layer extension (2026-07-13)

through theory, independent verifier, proof-gated memory, cognition runtime,
vector frontend, and finite-field frontend. The owned integration may expose
generic collection, correspondence, and render contracts; it may not add an
ARC operation or use evaluation observations to select the grammar. Freeze the
non-ARC curriculum, implementation, and ARC adapter binding before evaluation.

The next extension adds collection-level entity correspondence with complete
construction provenance under ADR-0025. Its source-domain candidate/sample
reduction and zero-negative-transfer gate is mandatory before the ARC adapter

Acceptance is the G5-LAYER experiment in `04_CAIRN_EXPERIMENT_LADDER.md` plus
the post-freeze first-40 and complete-400 no-false-acceptance reports. ARC score
improvement is a measured hypothesis, not a mandatory implementation threshold.
