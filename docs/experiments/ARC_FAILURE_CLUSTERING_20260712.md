# ARC failure clustering and second structural transfer

Date: 2026-07-12

The quarantined `cairn-arc-failure-audit` tool classified all resource-limited
tasks using content-free structural signatures: shape relation, palette
relation, uniform partition evidence, output/partition geometry, and change
density. The initial 68-task apparent cluster fragmented after adding partition
geometry, confirming that raw input/output size is not a mechanism family.

The first clean follow-up family was native-geometry partition extraction.
Generated non-ARC examples varied partition position, dimensions, separator,
palette, and distractors. CAIRN induced an entity predicate using relative
sibling features, including maximum occupied and maximum distinct structure.
Absolute-count transfer failed and was retained as a negative result; relative
features then transferred exactly.

Full-corpus applicability testing admitted three bindings and produced no false
acceptance. The complete frozen run confirmed 35/400 exact, 365 resource-limited,
and zero incorrect, versus the 32/400 blank baseline. No exact baseline task was
lost.

The next largest signatures remain heterogeneous same-shape partitioned edits
and irregular shape-reducing constructions. They require finer entity/event
signatures before another mechanism is selected.
