# Experience-driven relation-language growth

Status: `PASS_WITH_DECLARED_LIMITS`

## Frozen question

Can verified reusable experience and a content-free structural failure expand
the learner's bounded proposal language, instead of a developer enabling the
missing fold for the experiment?

## Causal attribution

The default grammar cannot enumerate a fold. Increasing maximum arity without a
fold capability also cannot enumerate one. The extension becomes available only
after the binary mechanism has two disjoint verifier receipts, a separate
consolidator has promoted it, and a redacted failure core requests arity three.
The certificate maps the promoted associative operator to its own fold family;
it does not copy an answer, expected partition, attribute binding, or task ID.

The new ternary mechanism is then learned from evidence and passes ordinary
independent replay and promotion. Ablating the language-extension certificate
returns the system to zero exact theories. The minimum-family replication
separates the mechanism from addition-specific control flow. A separate G5
test learns the newly reachable fold from sequence observations and rebinds the
same mechanism through the unchanged vector adapter.

## Claim boundary

This closes the configured-arity weakness of ADR-0049 for a small algebraic
class and demonstrates that learning can change future representational search.
It does not invent associativity, primitive scalar channels, arbitrary RKL AST
productions, recursion, or sensory entities. It is evidence toward a
self-expanding causal learner, not evidence that CAIRN is generally intelligent.
