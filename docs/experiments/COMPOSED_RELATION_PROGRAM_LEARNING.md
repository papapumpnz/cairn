## Attribution

Every atomic channel cuts across the intended groups. Only the sum of two
anonymous channels supplies the component key, and channel positions change by
episode and frontend. The learned identity contains executable relation RKL and
the downstream mechanism, not channel positions. Removing the structural
memory restores all five operator families. The verifier derives search counts
from the current candidate grammar and independently reconstructs every edge.

The curriculum result begins with a content-free relational failure core. The
curriculum chooses layout variation and requires two independent experiences;
the materialized evidence, verifier receipts, promotion, held-out transfer,
and restart record complete that objective without benchmark content.

## Claim boundary

This passes a bounded composed-relation invention and continual-reuse slice. It
is not general intelligence. The learner receives exact scalar attributes,
uses five developer-supplied key constructors, assumes finite clean evidence,
and still lacks learned sensory channels, nested/overlapping entities,
recursive relation paths in this frontend, and autonomous grammar expansion.
