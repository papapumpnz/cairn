# Continual local-law reuse

Status: passing bounded integration experiment; not a general-intelligence or
ARC pass.

## Question

Can a mechanism invented from ordinary finite observations enter strict memory,
then measurably reduce future learning work through the same generic invention
contract used by other domains?

## Frozen design

Two independent field experiences contain changed dimensions, categorical
values, counts, positions, and layouts. Neither receives a shift operator or
task-family label. Fresh bounded synthesis must induce the executable RKL body
`output := west` in each experience. Promotion requires cross-task support and
an independent verifier token.

The memory-on evaluation receives one 1x3 demonstration and a one-candidate
budget. The memory-off counterfactual uses a frozen 3x7 problem and the ordinary
search budget. A separate 5x7 field changes geometry, values, and positions for
held-out prediction.

## Failure discovered

The initial integration did not finish. Memory retrieval eagerly materialized
every type-compatible parameter permutation before checking the first proposal.
The local theory has 13 integer parameters, creating a 13! rebound space even
though the correct name-preserving binding is immediate.

This was corrected in the general `cairn-memory` crate. Direct semantic-name
bindings are proposed first. Direct and composed alternatives have an
independent hard maximum of 1,024.
Every attempted proposal is still type checked and replayed on the complete
current evidence by both executors.

## Result

| Measure | Memory disabled | Memory enabled |
|---|---:|---:|
| Candidate executions | 4 | 1 |
| Demonstration cells | 21 | 3 |
| Held-out exact cells | 35/35 | 35/35 |
| Incorrect accepted theories | 0 | 0 |

Fresh search fails under the one-candidate memory-on budget; the verified
rebound proposal succeeds and remains necessary under that ablation. The
executable held-out result is exact after geometry, categorical values, and
positions change.

## Reproduction

```text
cargo test -p cairn-field --test continual_local_transition -- --nocapture
```

The test performs independent invention, strict promotion, verifier-token
application, memory-off measurement, the fixed-budget ablation, current-task
replay, and held-out execution.

## Claim boundary

This establishes live continual reuse for one local causal-law class and
removes a high-arity retrieval blocker. It does not establish broad mechanism
discovery, cross-domain reuse, general intelligence, or an improved official
ARC-AGI-1 score. The complete ARC result remains 32/400; the required threshold
remains 320/400.
