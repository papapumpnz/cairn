# Anonymous interval-relation invention

Status: `PASS_WITH_DECLARED_LIMITS`

## Frozen question

Can downstream explanation invent enclosure from anonymous numeric endpoints
without a supplied geometry relation, pair labels, edges, or partitions?

## Method

Entities carry two anonymous integer attributes. Source groups contain one
interval strictly enclosing a variable number of other intervals. Crossing
hard negatives make one-sided endpoint tests connect different groups. The
learner optionally enumerates equality and order atoms, canonicalizes complete
pair reversal, builds components, and tests an unordered aggregate.

Two independent source cohorts use vector, sequence, table, and workflow labels.
Graphics and operations held-outs change all identities, coordinates, payloads,
group counts, cardinalities, and entity order.

## Interpretation

CAIRN synthesized a recognizable enclosure relation from the minimal numeric
substrate, and the definition—not a native geometry operator—crossed the
verifier boundary. This is a stronger omitted-concept result. It remains one-
dimensional, exact, feature-supplied, task-local evidence. Two-dimensional
geometry, derived feature construction, persistence/support testing for order
predicates, noise, and raw perception remain open. This is not general
intelligence or an ARC result.
