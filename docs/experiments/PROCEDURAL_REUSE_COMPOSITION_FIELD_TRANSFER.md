# Procedural reuse, composition, and finite-field transfer

Date: 2026-07-11

## Question

Can an offline-teacher proposal become measured procedural knowledge, transfer
unchanged across non-ARC adapters, compose with another independently learned
procedure, and reach ARC through a generic field binding without negative
transfer?

## Architecture changes

- Procedural modules retain independently verified reuse receipts. A
  provisional theory cannot become persistent until its canonical theory,
  proof lineage, verified cases, and measured reuse agree with a verifier token.
- Vector-graphics attributes and numeric sequences lower to the same generic
  collection contract; cognition contains no frontend checks.
- Collection distillation supports maps and filters. A filter lesson induces a
  Boolean RKL predicate from membership contrast and lifts it into a guarded
  variable-arity theory.
- Runtime pair search composes separately stored procedures and replays each
  schedule end-to-end. It receives no named composite operator.
- The generic finite-field bridge lowers distinct categorical values, executes
  admitted theories on singleton bindings, and must reconstruct every training
  cell exactly before ARC may use a prediction.

OpenAI and Anthropic orchestrators remain offline file-spool producers. Teacher
output remains provisional until local verification.

## Results

1. Premature procedural promotion was rejected. It succeeded after one
   independently checked, necessary-under-ablation receipt.
2. One learned `2*x+1` theory had the same module identity and exact held-out
   predictions through sequence and vector adapters.
3. Three variable-cardinality episodes produced an executable `x < 0`-equivalent
   selector that transferred to a five-input/two-output held-out collection.
4. Neither map nor selector solved the composition task alone. Pair search used
   both learned modules and exactly predicted `{-23, -9}`.
5. The map reconstructed a held-out 2D field exactly. On the frozen first 20
   ARC-AGI-1 training tasks, procedural memory produced 17 exact, 3
   resource-limited, and 0 incorrect results—the same accuracy as blank memory.

## Interpretation

This is evidence of executable cross-domain reuse and novel two-procedure
composition. It is not evidence of general intelligence, and it did not improve
the frozen ARC score. The next bottleneck is structural entity-collection and
render-binding induction, not ARC-specific transformations.
