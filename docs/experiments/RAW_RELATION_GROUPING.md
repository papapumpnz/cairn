# Raw relation-edge grouping experiment

Status: `PASS_WITH_DECLARED_LIMITS`

## Frozen question

Can CAIRN construct candidate entity collections from raw generic relation
edges, select a relation by executable explanatory adequacy, and retain the
result so future raw-edge tasks require less search and no demonstrations?

## Method

Four independently named source episodes span vector, sequence, table, and
workflow modalities. Each contains opaque entity identities, scalar evidence,
and edges for two relation roles. No partition or selected relation is present.
The correct role connects variable-size collections whose output is their
learned span. The distractor connects the same entities into equal-count,
identical-evidence components, so it cannot emit distinct unordered outputs.

The producer and independent verifier implement separate connected-component
paths. Two independent cohorts produce the same relation-bound RKL mechanism;
the existing consolidator and memory gate promote it. Held-out graphics and
operations episodes increase component counts and change identities, topology,
values, and cardinalities.

## Measured result

```text
relation roles observed: 2
selected partitions supplied: 0
independent learning cohorts: 2
fresh candidate executions / memory attempts: 187 / 1
fresh examples / memory examples: 4 / 0
held-out components independently replayed: 13 / 13 exact
blank-memory proposals: 0
unknown/duplicate/capped evidence accepted: 0
edge-order or direction changes: 0
```

## Interpretation

This advances ontology construction from supplied groups to learned collection
hypotheses over raw relation evidence. It does not invent the primitive relation
predicates themselves and does not perform perception from pixels, geometry, or
language. Durable CAS restart, richer relation-definition invention, and an ARC
adapter binding remain open. No general-intelligence or ARC-score claim follows.
