## Known limits

- Source inspection is conservative lexical/structural analysis rather than a
  complete Rust semantic model. Cargo dependencies and activated features use
  Cargo's resolved metadata rather than text matching.
- Build scripts are inspected but never executed by the checker. Native flags
  already emitted by a prior build are not trusted as proof of a clean source
  tree; runtime loaded-library inspection supplies the second boundary.
- Hosted CI has not run in this workspace.
- Runtime observations are Linux `/proc`-based where portable standard-library
  APIs do not expose equivalent facts; unavailable fields remain explicit.
