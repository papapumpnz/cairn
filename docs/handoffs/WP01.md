## Scope delivered

- Strict bounded canonical CBOR profile with RFC 8949 preferred integer and
  float widths, canonical map ordering, duplicate-key rejection, normalized
  NaN, and rejection of non-canonical input.
- BLAKE3 `Hash32`, distinct semantic `ArtifactId` and physical `BlobId` types.
- Versioned `ArtifactEnvelope<T>` construction, full canonical encoding and
  decoding, independent payload/identity reconstruction, sorted parent lineage,
  producer/resource metadata separation, and exact semantics negotiation.
- Fail-closed `SchemaRegistry` and explicit `AdditiveMapReader` for compatible
  older fields without rewriting canonical bytes.
- Append-only fanout CAS using synchronized temporary files and atomic
  no-clobber publication, immutable registrations, bounded reads, collision
  diagnostics, corruption validation, thread/process idempotency, and recovery.
- Typed envelope-to-CAS integration and safe zero-copy slices over verified
  shared byte snapshots.
- JSON diagnostic artifact schema, benchmark, fault-injection worker, acceptance
  runner, dependency audits, and ADRs for identity and safe snapshot reads.

Semantic artifact identity follows ADR-0001. Producer, actual resource use,
logical creation order, and signature do not change the ID. Physical envelope
bytes retain those fields and therefore have a distinct `BlobId`.

## Correctness and determinism

- Canonical inputs are decoded and re-encoded before acceptance.
- Golden bytes cover integer, negative, bytes, text, array, map, and float
  forms; randomized values exercise nested forms.
- Envelope loading revalidates CAS blob hash, canonical payload, payload hash,
  schema, semantics version, parents, and semantic artifact ID.
- Fake constant hashing proves different bytes cannot overwrite an accepted
  blob even under an identity collision.
- Filesystem and parent traversal order is sorted before semantic decisions.

## Known limits

- Under ADR-0002, the accepted read interface uses safe immutable byte snapshots
  rather than unsafe file-backed memory maps. This is the declared limit behind
  `PASS_WITH_DECLARED_LIMITS`; the mandatory performance threshold still passes.
- Canonical CBOR tags and indefinite-length encodings are intentionally outside
  the profile and fail closed.
- CAS packfiles, compression, remote replication, and signatures are future
  package concerns; signature bytes are preserved but cryptographic signature
  verification is not claimed here.
- Hosted CI has not run in this workspace.

## Downstream start condition

WP04 may start directly from `wp01-artifact-v0.1.0`. WP03 may start when WP02 is
also tagged. Every downstream persistent type must implement canonical encoding,
declare schema and semantics versions, and use distinct `ArtifactId`/`BlobId`
semantics. Downstream acceptance must run `scripts/wp01_acceptance.sh` unchanged.
