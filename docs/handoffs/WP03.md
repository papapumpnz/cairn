## Scope delivered

- Environment-neutral typed nodes for observations, entity hypotheses,
  actions, states, events, roles, latent variables, definitions, goals, skills,
  and knowledge claims.
- Typed binary and hyperedge relation definitions with exact arity and node-kind
  validation.
- Append-only acyclic derivation records with operation hashes, inputs,
  parameters, semantics versions, and public `DerivationArena` views.
- Immutable published snapshots, concurrent readers, and isolated append-only
  extension from an existing snapshot.
- Deterministic relation/argument, node/fact attribute, and logical-time indexes.
- Deterministic conjunctive joins with bound-variable index selection, typed
  attribute filters, bounded directed path constraints, and grouped counts.
- Exact and fixed-point uncertain evidence weights without non-canonical floats.
- Canonical CBOR encoding plus bounded semantic decoding that reconstructs and
  revalidates every index and rejects semantic reordering.
- Independent randomized relational-reference comparisons and measured CPU
  benchmark.

## General-learning boundary

The crate depends only on `cairn-core`. It contains no spatial field, grid,
color, ARC, RKL execution, synthesis, memory, or adapter dependency. Spatial,
interactive, vector, and knowledge frontends lower their evidence into the same
nodes, relations, attributes, times, and derivations.

## Known limits

- Extending a snapshot currently clones the immutable base before appending.
  This preserves correctness and isolation but is not persistent-segment
  structural sharing.
- Sparse deterministic argument indexes already exceed the performance gates;
  specialized dense binary adjacency is therefore deferred until profiling
  demonstrates a measured need.
- Query planning is a deterministic caller-specified left-deep order. Automatic
  cost-based join reordering is downstream optimization, not current semantics.
- Hosted CI has not run in this workspace.

## Downstream start condition

WP05 and WP07 may consume `wp03-reg-v0.1.0` together with
`wp04-rkl-v0.1.0`. WP06 may start after WP05. Downstream packages must preserve
the immutable snapshot and typed provenance boundaries and cannot introduce a
spatial or adapter dependency into `cairn-reg`.
