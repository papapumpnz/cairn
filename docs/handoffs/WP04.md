## Scope delivered

- Modality-neutral bounded RKL type universe, including uninterpreted `Atom`
  values and bounded `FiniteField` observations rather than color/grid core
  types.
- Expression AST, debug S-expression parser, exact type/range inference,
  collection bounds, free-variable tracking, predicate admission, direct
  recursion bounds, and bounded fixpoint fuel.
- Low-level definitions, binders, rules, generic effects, schedules, renderer,
  and complete `Theory`/`CheckedTheory` admission boundary.
- Duplicate definition/rule/binder rejection, finite binder-domain checks,
  state-effect checks, Boolean guard/assumption checks, unknown schedule-rule
  rejection, dependency-cycle detection, and explicit rejection of mutual
  recursion.
- Canonical CBOR for types, checked expressions, definitions, and checked
  theories; alpha normalization; associative/commutative normalization; stable
  semantic BLAKE3 hashes; proof lineage excluded from identity.
- Deterministic structural cost model with literal and maximum-step accounting.
- Reproducible acceptance runner and focused generic-RKL regression evidence.

## Known limits

- WP04 defines and validates semantics. It does not execute RKL; WP05 owns the
  independent reference and optimized executors.
- Direct recursion requires explicit maximum steps and an integer progress
  expression. Mutual recursion is rejected rather than assigned unclear fuel
  semantics.
- RKL is intentionally low level. Ontology invention, high-level mechanisms,
  and adapter rendering remain downstream definitions rather than new native
  operations.
- Hosted CI has not run in this workspace.

## Downstream start condition

WP05 and WP12 may consume `wp04-rkl-v0.1.0`. WP23 may use the typed module
contract once WP06 is available. All downstream code must accept `Atom`,
`FiniteField`, `Emit`, and checked-theory canonicalization and must not restore
ARC-specific semantics to RKL.
